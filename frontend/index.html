What is OpenRouter?

OpenRouter (opens in a new tab) is one API that routes to many models. CogniGraph calls it once per scenario to classify your text, then runs the brain simulation on this server. You only need an OpenRouter account if you choose to add your own key. If this deployment has no server key (for example some self-hosted installs), add a key here or configure OPENROUTER_API_KEY on the server.
