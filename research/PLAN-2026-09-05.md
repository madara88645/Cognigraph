## Non-negotiables

- Fully client-side. No backend, no API keys, no fetch except CDN scripts + Google Fonts.
- Scripts only from `cdn.jsdelivr.net/npm/` (three core + addons at ONE pinned version) —
  cdnjs does not host three's addons. Verified URLs: `three@0.170.0/build/three.module.js`,
  `three@0.170.0/examples/jsm/{controls/OrbitControls,postprocessing/EffectComposer,RenderPass,UnrealBloomPass}.js`.
- Noise is inlined (small simplex-3D implementation) — one less CDN dependency.
- Every technical term in rendered text → clickable glossary popover (auto-linker).
- Persistent "Explain this" panel; "How this simulation works" drawer separating physiology
  from metaphor; visible non-medical/educational disclaimer.
- Elegant minimal dark UI: glass panels, one accent per mode, Inter (Google Fonts) + system
  fallback, monospace for numbers. No clutter, no shadow maps, DPR capped at 1.5.

## What the user sees (product summary)

Full-screen 3D brain you can orbit. Top bar with three pills: **Pathways / Atlas / Neurons**.
Left glass panel = controls for the active mode. Bottom-right glass card = **Explain this**,
always visible, updates with whatever is hovered/selected/animating. `?` opens the
**How this works** drawer. Cortex opacity slider so subcortical structures show through.

1. **Pathways** — pick one of 8 scenarios; regions light up in order, a pulse travels between
   them along a curve, camera eases to each step, timeline scrubber at the bottom shows
   approximate ms (or "schematic order" for the two slow ones). Each step explains what
   happens, why it matters, and what evidence it rests on; caveats always visible.
2. **Atlas** — searchable list of 28 regions grouped by lobe/system; click list or brain.
   Card: one-liner, functions, location, connections (clickable), lesion effects, famous
   case. **Lesion mode** toggle: clicking greys a region out and shows what breaks; multiple
   lesions allowed; reset button.
3. **Neurons** — 150 Izhikevich neurons (120 E / 30 I, Dale's law, 10% sparse random
   connectivity) running live; raster, membrane trace, population rate; 6 neuromodulator
   sliders each with "in real circuits / in this sim" text + an honesty badge; neuron-type
   presets (RS, IB, CH, FS, LTS, TC); advanced a/b/c/d + phase portrait behind a toggle.

```
    data/neuro.js          # NEUROMOD_DEFS (6), NEURON_PRESETS (6), PITFALLS (13), HOW_IT_WORKS text
    brain/geometry.js      # hemispheres, cerebellum, brainstem, subcortical primitives
    brain/parcellation.js  # cortical region patches (center dir + angular radius), lobe fallback

  tests/*.test.mjs         # node --test on pure modules (noise, parcellation, linkTerms, neurons-core)

```

- Source files use `export`/local `import` for testability; `build.py` strips local imports
  and `export ` prefixes and emits one `<script type="module">` (file:// blocks local module
  imports, CDN imports are fine). Importmap goes at the very top of the file (Artifact wraps
  the file in its own head/body; importmap must precede the module script and does).
- Rendering: one WebGL canvas; UI is HTML/CSS overlays; neuron plots are 2D `<canvas>`.
- State: one small `app` object with `mode`, `selection`, `lesions`, `pathway` playhead,
  `neuron` params; each mode module exposes `enter()/exit()/update(dt)`.

## Brain model recipe (procedural)

- Hemispheres: `IcosahedronGeometry(r, 5)` ×2, scaled to brain ellipsoid, lobe bulges via
  smoothstep masks, flattened medial face, displaced along normals by 3-4 octave fBm
  (amplitude 3-6 % of radius, low-freq folds + high-freq texture), recompute normals,
  longitudinal fissure by ±offset. Material: `MeshPhysicalMaterial` translucent blue-gray,
  opacity slider (default ~0.35), Fresnel rim via `onBeforeCompile`; transmission only in
  High quality on WebGL2.
- Cerebellum: smaller ellipsoid with fBm + directional sine ripple (folia look).
- Brainstem: `LatheGeometry` profile (midbrain → pons → medulla → cord stub).
- Subcortical meshes (each with `userData.regionId`): thalamus (paired eggs), hypothalamus,
  amygdala (almonds), hippocampus (`TubeGeometry` on C-curve), striatum (caudate tube +
  putamen lens), globus pallidus, STN, nucleus accumbens, VTA, substantia nigra, locus
  coeruleus, raphe (midline pearls), corpus callosum (flattened C tube), insula (shown as an
  exposed patch with a note that it is really folded inside the lateral sulcus).
- Cortical regions: NOT separate meshes. Per-vertex `regionId` attribute assigned by
  nearest region-center-direction within that region's angular radius (12 patches per
  hemisphere, mirrored; Broca/Wernicke left only + note); unassigned vertices fall back to
  lobe id. Raycast hit → face → majority vertex regionId. Highlight via per-vertex
  `highlight` attribute lerped in the shader (soft glow, no hard outline).
- Region centroids computed at build for camera fly-to and pathway curves.
- Budget: ~100k triangles total, `InstancedMesh` for pulses/neuron dots, target 60 fps.

## Neuron simulation spec

Izhikevich 2003: `v' = 0.04v² + 5v + 140 − u + I`, `u' = a(bv − u)`, spike at v ≥ 30 →
v=c, u+=d. dt = 0.5 ms, two half-steps for v then one u update per 1 ms; threshold checked
every sub-step; `isFinite` guard resets divergent neurons. N=150 (120 RS, 30 FS), fixed
random 10 % adjacency in `Int32Array`, exponential synaptic currents (τE 5 ms, τI 10 ms),
1-step delay, Gaussian noise, E/I drive balanced. Speed slider 0.25×-8×.
Neuromodulator mappings (each with badge): DA tonic offset on a labeled subgroup
(directional), ACh lower `d` + weaker recurrent E→E (well-supported), NE gain on net current
(well-supported), 5-HT E/I set-point shift (simplified), GABA tone = inhibitory weight gain
(direct), Cortisol = noise + excitability composite (metaphor).
Plots on 2D canvas: raster (E/I colored, rolling window), v & u trace for up to 3 highlighted
neurons, population rate E vs I, optional v-u phase portrait with nullclines.

## Product changes
1. **Rebrand** strings only: title/brand "CogniGraph", About tab, README. Keep `window.NeuroScope` as an alias of `window.CogniGraph`.
2. **Scenario mode** (4th pill, accent: coral). User types a scenario (or picks one of the old 6 presets).
   - `src/llm/classify-local.js` — keyword/heuristic fallback, no key needed (maps to the closest of the 8 pathways + a neuromodulator profile).
   - `src/llm/openrouter.js` — `fetch('https://openrouter.ai/api/v1/chat/completions')` with the user's key from localStorage
     (`cg.openrouter.key`), model configurable (`cg.openrouter.model`, default a cheap fast model), JSON-mode prompt,
     strict validation/hardening like the old backend (unknown region ids dropped, values clamped, fallback to local).
   - Output schema: `{title, steps:[{region_ids[], what_happens, why_it_matters, approx_ms|null}], neuromodulators:{dopamine, acetylcholine, noradrenaline, serotonin, gaba, cortisol: 0..1}, intensity, rationale, confidence}`.
   - Playback: convert to a PATHWAYS-shaped object and reuse the Pathways engine (pathways.js must export `pwPlayExternal(pathwayObj)`);
     "Send to Neurons" applies the neuromodulator profile to the sliders (neurons-ui.js exports `nsApplyModulators(profile)`).
   - Honesty: Explain badge "LLM-generated, not evidence" (`.badge.low`), rationale shown verbatim, local-fallback badge when no key.
   - Settings tab in the drawer: key input (password field), model select, "stored only in this browser, sent only to OpenRouter" note, Clear.
   - CSP: the Artifact sandbox blocks fetch → detect and show "Scenario mode needs the hosted version (Vercel) or the local file".
3. Old presets (Academic Exam Stress, Deep Focus, Creative Brainstorming, Public Speaking, Competitive Gaming, Social Campfire) come back as one-click examples.
